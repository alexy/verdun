# Verdun

*Verdun: A Framework for Shared Work* is the First Pair Press edition of the
Verdun codebase guide, by Alexy Khrabrov. Its canonical source is
`manuscript.md`; generated full-edition artifacts belong in `dist-full/`.

The book is deliberately a guide to the reusable framework rather than a
product manual. It follows the repository's ownership boundary: external
applications own their domain behavior; Verdun owns the shared workbench,
account, crawler, database, and deployment contracts.

The full Obsidian reader vault and the compact mobile reader vault are derived
from this manuscript and from the current codebase. They are generated only
when their target folders are closed in Obsidian.
